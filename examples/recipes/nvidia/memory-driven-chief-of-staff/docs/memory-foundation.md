# Recoverable memory writes

Foundation coordinates Markdown pages, the shared index and log, and the page
registry through a recoverable journal. Generated content needs no per-page
approval after enablement. Existing handwritten fields remain unmanaged until
an explicit scoped adoption and review.

The [complete protocol guide](../profile/scripts/memory-protocol.md) ships with
the profile as `$HERMES_HOME/scripts/memory-protocol.md`, so scheduled skills
can read the same interface contract without access to this repository.
It covers installation and enablement, proposal examples, field ownership,
project logs, user actions, recovery, completion extensions, export, and reset.

Foundation adds no entity extraction or new page-generation job. The current
writer continues to maintain people and attention through the coordinated
transport. Feedback learning and the project/pattern/concept generators remain
separate work.
