## Collector defect and fix

Pod log HTTP responses may start with JSON configuration and continue with ordinary text or JSON Lines. They are log text, not Kubernetes resource documents. Upstream main's content-prefix heuristic incorrectly calls `json.loads` and can raise `JSONDecodeError: Extra data`, stopping that collection cycle.

The local patch recognizes the exact namespaced Pod `/log` subresource, requests `text/plain`, and preserves its text. Query parameters for container, tail lines, and previous logs are retained. Pod/Service/ConfigMap resources named `log` still use strict resource JSON parsing. Invalid resource JSON becomes a controlled `KubeError` without including resource contents in its error text. Optional log decoder/transport failures do not abort detection.

This collector defect is separate from the LLM. A newly tested model edge case is also handled: a non-text completion becomes a controlled retryable `LLMUnavailable` rather than an uncaught Python `TypeError`.

## Verification

`tests/test_autoheal_runtime.py` imports the runtime shipped by this child chart. Its test-only `SRE_AUTOHEAL_TEST_SOURCE` override permits comparison against a separate upstream checkout without modifying either source tree.

Collector tests against pristine GitHub main fail as expected, including the mixed JSON/text and JSON Lines reproductions. Against the local patched runtime, all 18 regression tests pass.

After merging NVIDIA main and the fork's projected-token rotation and scoped-cleanup fixes on October 5, the complete local SRE recipe suite passes 71 tests, and the complete Kubernetes Deployer suite passes 94 tests. These suites ran in an isolated validation copy because chart tests rebuild Helm dependencies. Existing working-tree chart dependencies were not regenerated by those tests. The resilience tests are separate from the credential-rotation tests so neither regression suite replaces the other.

The original 78-test auto-heal suite also passes when importing this community runtime explicitly, covering policy, detection, retry persistence, notifications, and outcome memory. Child chart Helm lint and `git diff --check` pass. Expected mocked warnings include denied test recipients and simulated persistence failure; no real notifications or cluster operations occur.

These results are local regression/render validation, not live admission, inference compatibility, notification delivery, or operational recovery. The Hermes WebUI dependency replacement and external-backend integration remain separate from this bounded bug fix.
