Sandbox lifecycle (no local OpenShell binary required)
The chart does not render a Sandbox object and never deletes the sandbox or the
retained Hermes PVC during `helm uninstall`. To retire the sandbox, let the
authenticated bootstrap Job delete it, verify, then uninstall:
  helm upgrade {{ .Release.Name }} <chart-path> -n {{ .Release.Namespace }} --reuse-values \
    --set lifecycle.sandbox.desiredState=absent \
    --set lifecycle.sandbox.dangerousAcknowledgement=I_ACKNOWLEDGE_SANDBOX_DELETE --wait
  {{ $cli }} -n {{ .Release.Namespace }} get sandbox default--{{ $sandbox }}   (expect NotFound)
  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
{{- end }}
