**Scheduled maintenance — internal DNS rotation**

Platform Eng Ops will be rotating the keys on the internal authoritative DNS
resolver this week. The change is hot — no expected downtime — but we want
service owners to know in case they see brief resolution blips on long-lived
processes.

| Field | Value |
| --- | --- |
| Start | Wednesday 2026-05-13, 22:00 UTC |
| End | Wednesday 2026-05-13, 22:30 UTC (estimated) |
| Duration | ~30 minutes |
| Affected systems | internal `.examplecorp.example` DNS resolution from corp network and clusters |
| Unaffected | external DNS; VPN auth; SSO |

**What to expect**

- Long-lived JVMs and Python processes that cache DNS for hours may briefly
  see `NXDOMAIN` or stale resolution during the cutover. Most services with a
  60s TTL will recover automatically.
- If your service uses pinned IPs (please don't), refresh them after 22:30.

**Action**

- If you operate an always-on process that you suspect caches DNS, schedule a
  graceful restart for Thursday morning local time.
- Atlas, Beacon, Compass on-call engineers: please ack on the status page.
