**[P2] Repeated `Path.resolve()` per wave is wasteful**

`start_wave` runs hundreds of times per ingest cycle. `Path.resolve()` performs a `stat` on every parent. Resolve once at config load and cache the resolved value on the config object.

```python
# src/atlas/config/__init__.py
class AtlasConfig:
    def __init__(self, data: dict):
        ...
        self._wiki_root_cached: Path | None = None

    @property
    def wiki_root(self) -> Path:
        if self._wiki_root_cached is None:
            self._wiki_root_cached = resolve_wiki_root(self)
        return self._wiki_root_cached
```
