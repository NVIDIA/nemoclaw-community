**[P1] Inverted index unbounded for sections with many unique tokens**

`ContextSelector.__init__` adds every token from every section to `self._index`. A 50 KB section can contribute ~8000 distinct tokens. For 400 sections the dict can balloon to several MB — fine in steady state but a noticeable spike on construction. Cap each section's contribution to its top-K most discriminative tokens (e.g. top 256 by inverse-document-frequency rank already computed for the cache key).

```python
def _tokens_for_index(section: Section, top_k: int = 256) -> list[str]:
    ranked = sorted(section.tokens_with_idf(), key=lambda t: -t.idf)
    return [t.value for t in ranked[:top_k]]
```
