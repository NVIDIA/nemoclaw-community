**Branch**: `perf/dedupe-wiki-reads` &rarr; `main`

## Summary

A single batch session re-reads the same wiki pages 5–8x while building per-item context (one read per item, plus the consolidate pass). This MR caches reads inside the session boundary and invalidates on the wiki group mutex release. Cuts wall time on a 40-item wave by ~22% in local profiling and removes the duplicate prefix-cache misses we were paying for on the prompt prefix cache.
