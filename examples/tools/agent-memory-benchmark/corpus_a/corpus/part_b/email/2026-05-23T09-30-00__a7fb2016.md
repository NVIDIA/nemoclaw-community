**P1 — `WikiCache._hit_counter` is read-modify-written without a lock**

`WikiCache.get` increments `self._hit_counter` on a hit and `self._miss_counter` on a miss. Two sessions sharing a cache (which is the intended deployment per `docs/design/wave_ingest.md`) will lose counter increments under contention. The values are exposed via `WikiCache.stats()` and propagated to metrics, so we'll under-report cache effectiveness on busy waves. Use a lock or switch to `itertools.count`/atomic primitives.

```python
import threading

class WikiCache:
    def __init__(self) -> None:
        self._lock = threading.Lock()
        self._hit_counter = 0
        self._miss_counter = 0

    def get(self, page_id: str) -> tuple[PageRef, ...] | None:
        entry = self._entries.get(page_id)
        with self._lock:
            if entry is None:
                self._miss_counter += 1
            else:
                self._hit_counter += 1
        return entry.pages if entry else None
```

**P1 — `PageRef` is a non-frozen dataclass; tuple wrapper doesn't prevent field mutation**

The previous P1 fix made `WikiCache` return a `tuple[PageRef, ...]` — but `PageRef` itself is a regular `@dataclass` in `src/atlas/stores/wiki_store.py`, so callers can still do `pages[0].body = "..."` and corrupt the cached entry. The tuple boundary stops list-level mutation but not field-level mutation. Make `PageRef` frozen, or return deep copies.

```python
@dataclass(frozen=True, slots=True)
class PageRef:
    page_id: str
    title: str
    body: str
    revision: int
```

**P2 — `inspect_cache_for_debug` writes page bodies to the agent log**

`WikiCache.inspect_cache_for_debug` (added in this MR) dumps the full entry contents — including page bodies — at INFO level. That's fine when running with `LOG_LEVEL=DEBUG` locally but it's currently unconditional, which means production logs will contain user-content snippets. Gate it on the debug level, or strip the body in the production path.

```python
def inspect_cache_for_debug(self, logger: logging.Logger) -> None:
    if not logger.isEnabledFor(logging.DEBUG):
        return
    for page_id, entry in self._entries.items():
        logger.debug("wiki_cache entry id=%s status=%s n_pages=%d",
                     page_id, entry.status, len(entry.pages))
```
