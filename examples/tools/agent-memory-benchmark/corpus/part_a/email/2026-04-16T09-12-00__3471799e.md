### Summary

Split the ingest pipeline into typed waves so that email, chat, and wiki sources each run through their own wave class instead of a single polymorphic loop. This makes the per-source state-machine explicit, lets the wave-commit step batch per-type, and unblocks the prefix-cache work that needs a stable wave shape.
