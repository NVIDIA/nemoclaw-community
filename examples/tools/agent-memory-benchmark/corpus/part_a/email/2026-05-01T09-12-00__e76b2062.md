**Branch:** `fix/wave-commit-race` → `main`

### Summary

Fix a race in the wave-commit transaction that shows up under load when two waves try to advance the same `ingest_state.last_wave_seq` row. The current code reads-then-writes without `BEGIN IMMEDIATE`, so two waves can both observe the same `last_wave_seq`, both increment, and end up writing rows under a duplicated seq. This MR upgrades the commit path to a single `BEGIN IMMEDIATE` and adds a regression test that reproduces the race deterministically.
