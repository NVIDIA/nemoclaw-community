# Chat Developer Newsletter — May Edition

Hi developers,

A few items worth your attention if you build bots on the chat platform.

**1. Block Kit "confirm" object: now supported in modal submit**

Previously the `confirm` object was only honoured on plain button actions.
You can now attach a `confirm` to modal submit actions — useful for "are you
sure?" prompts before a destructive workflow. Old modals continue to work
unchanged; just add the `confirm` field where you want it.

Docs: https://developers.chatplatform.example/docs/block-kit/confirm

**2. New webhook retry budget**

Outgoing webhooks now retry up to 3 times with exponential backoff (1s, 4s,
16s) instead of 5. A long tail of bots was holding worker time by returning
5xx for hours. If you legitimately need more retries, return 202 and queue
internally.

**3. Deprecation: `chat.postMessage_legacy` sunsets 2026-09-01**

The replacement (`chat.postMessage`) has been GA for 18 months and is a
drop-in for 99% of callers. Audit your code for the `_legacy` suffix.

**4. Field spotlight**

A short writeup on how a sibling team mirrors GitLab MR review activity into
a triage channel. Worth a skim if you're building anything similar.

Read it: https://developers.chatplatform.example/blog/2026-05-mr-mirror
