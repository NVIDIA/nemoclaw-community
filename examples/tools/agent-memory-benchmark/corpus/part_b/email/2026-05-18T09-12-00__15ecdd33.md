## feat: selective context inclusion in batch prompt

Branch: `awa/atlas-selective-context` -> `main`

Add a per-item context selector to the wave ingest path so the batch prompt only includes the wiki sections each item actually references. The selector emits a stable subset key so the prompt prefix cache still hits; cache hit rate on the smoke fixture goes from 71% to 94%.
