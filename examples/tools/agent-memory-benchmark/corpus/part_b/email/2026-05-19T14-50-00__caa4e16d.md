**[P1] Cached `prompt_layout` survives config reload**

The PromptBuilder is constructed once per ingest service start and reused. `cfg.reload()` does not invalidate `self._layout`. This is the same bug class as pass-3 of MR !489: once you cache derived state on a long-lived object you have to register an invalidation hook. Either hook into the same `AtlasConfig` invalidation callback list, or re-read `prompt_layout` per `build()` (the cost is one dict lookup — measure before optimizing).

```python
class PromptBuilder:
    def __init__(self, cfg: AtlasConfig):
        self._cfg = cfg
        cfg.register_invalidator(self._invalidate)

    def _invalidate(self) -> None:
        self.__dict__.pop("layout", None)

    @cached_property
    def layout(self) -> str:
        return self._cfg.get("ingest.prompt_layout", "legacy")
```

**[P2] `_tokens_for_index` recomputes IDF unnecessarily**

`section.tokens_with_idf()` is computed on every selector construction. The Section class already exposes a memoized `idf_ranked_tokens` property used by the consolidator. Reuse it.

def _tokens_for_index(section: Section, top_k: int = 256) -> list[str]:
    return section.idf_ranked_tokens[:top_k]
