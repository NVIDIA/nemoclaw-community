**[P1] `WeakMethod` only works for bound methods; plain functions silently break**

`weakref.WeakMethod(cb)` raises `TypeError` if `cb` is a plain function or a closure. The current code catches that broadly and skips registration — a registered callback that happens to be a plain function is then silently never invoked. Either accept both bound methods (via `WeakMethod`) and bare callables (via `weakref.ref`, with a wrapper) or document loudly that only bound methods are supported.

```python
def register_invalidator(self, cb: Callable[[], None]) -> None:
    if hasattr(cb, "__self__"):
        self._invalidators.append(weakref.WeakMethod(cb))
    else:
        # bare callable: caller owns lifetime, hold strong ref but warn
        log.warning("invalidator %r held by strong ref; prefer bound method", cb)
        self._invalidators.append(_StrongRef(cb))
```
