**P2 — Missing docstring on `CacheStats`**

`CacheStats` is exported from `wiki_cache.py` and consumed by the metrics service; downstream readers see only the type name without context. Add a one-liner describing what the snapshot represents and the invariant that `hits + misses == total`.

```python
@dataclass(frozen=True, slots=True)
class CacheStats:
    """Immutable point-in-time snapshot of a WikiCache's hit/miss counters.

    Invariants: hits + misses == total at the moment stats() returned.
    Consumers may compute hit_rate without re-locking the cache.
    """
    hits: int
    misses: int
```
