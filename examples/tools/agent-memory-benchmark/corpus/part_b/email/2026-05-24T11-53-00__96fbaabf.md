**Heads-up: service-key rotation — Friday 2026-05-29, 16:00 UTC**

Platform Eng Ops will rotate the shared service-account credentials used by
Atlas, Beacon, and Compass to talk to the internal artifact store and the
metrics ingestion endpoint.

| Field | Value |
| --- | --- |
| Start | Friday 2026-05-29, 16:00 UTC |
| End | Friday 2026-05-29, 16:30 UTC (estimated) |
| Affected systems | artifact store push/pull; metrics push API |
| Unaffected | git push/pull; CI pipelines; user SSO |

**Action required**

- Services that pull the config values from the secure config manager at startup will
  pick up the new values on their next restart — **no action needed**.
- Services that cache credentials in memory **must restart** within 24h of
  the rotation, or pushes will start failing with 401 on Sunday.
- Atlas, Beacon, Compass on-call: please confirm on the status page that
  your service is in the "auto-refresh" bucket.
