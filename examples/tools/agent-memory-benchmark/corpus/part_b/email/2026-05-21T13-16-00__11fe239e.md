Team,

Heads-up on the Compass v2 launch — calendar invite for the cross-team kickoff is coming in the next day or two; this note is to give context so it's not a surprise.

What v2 is:
- A rewritten metrics pipeline with much tighter freshness guarantees (seconds, not minutes) and a stable schema for downstream consumers like Atlas dashboards.
- The legacy v1 endpoint stays alive through end of Q3 to give consumers a clean migration window. After that it's read-only and the v1 → v2 migration tool is in the doc below.

What this means for Atlas specifically:
- Two dashboards Alex's team owns currently read from `metrics.v1.*`. Those will need to move to `metrics.v2.*` — same dimensions, mostly same names, with the rename map in the migration guide.
- The events Atlas emits today go to v2 automatically; no code change needed on the producer side. We did the dual-write in March.
- Expect a small bump in pipeline latency on the day of cutover. We're rolling cohort-by-cohort to keep blast radius small.

Cutover window: June 3 to June 6. Specific cohort dates will be in the calendar invite.

Migration guide + rename map: https://wiki.examplecorp.example/compass/v2-migration

Owners I'd like at the kickoff: Alex (Atlas), Rohan (Beacon consumers), Felix (CI metrics that feed dashboards). Calendar invite within 48h.
