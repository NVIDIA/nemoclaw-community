Quick FYI — Beacon hit its 50% rollout milestone this morning. Took longer than we wanted but the cohort numbers are stable, which is the part that matters.

Highlights:
- p99 latency held within 8% of the pre-rollout baseline. Mostly attributable to the new evaluator path; Anya is profiling, no fires.
- Error rate flat. No new categories of failure showed up post-cutover.
- Memory headroom on the runtime nodes is fine. The shared-abstraction refactor we did with Alex's team last sprint paid off here — same code path runs both products and the working set didn't double.

What's next:
- 75% cohort target: May 28. We'll watch the long-tail metrics for another week before opening it up further.
- The Atlas/Beacon shared-runtime sync this Friday will cover lessons learned; agenda will go out tomorrow.
- Anya is writing up the eval methodology — that'll be its own thread, expect it later this week.

Thanks to the Atlas folks (Alex, Jordan) for the patience on the shared-runtime work. The seams held.
