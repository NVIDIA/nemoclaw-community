### ReviewBot Summary

This MR hoists wiki path resolution out of `storage/wiki_writer.py` into `config/paths.py` and updates three call sites to use the new helper. The shape of the refactor is sensible: a single anchor reduces drift between cron, ingest, and the CLI. However, the new `resolve_wiki_root()` swallows a `KeyError` when `wiki_root` is missing from the config object, and the caller in `wave_runner.py` no longer asserts the path exists before kicking off ingest. The test update only covers the happy path. I'm flagging three issues that should land before merge.

**[P1] Silent fallback when `wiki_root` is unset**

`resolve_wiki_root()` returns `Path.home() / ".atlas" / "wiki"` if the config key is missing. That hides misconfiguration: a user who forgot to set `wiki_root` will silently write to a stray home-directory folder instead of getting a startup error. Atlas's wiki group mutex assumes one canonical root; a stray root will produce two mutex domains and the second writer will see "clean" state forever.

```python
# src/atlas/config/paths.py
def resolve_wiki_root(cfg: AtlasConfig) -> Path:
    root = cfg.get("wiki_root")
    if root is None:
        raise ConfigError("wiki_root is required; set it in atlas.toml")
    return Path(root).expanduser().resolve()
```

In `src/atlas/config/paths.py`, the `resolve_wiki_root` function currently falls back to a hardcoded default when `cfg.get("wiki_root")` returns `None`. Replace the fallback with an explicit `ConfigError` that names the missing key and points at the config file path. Update the docstring to state that the function never returns a synthesized default.

**[P2] `wave_runner.py` no longer validates the resolved path before fan-out**

The pre-refactor code called `wiki_writer.ensure_root()` which both resolved and stat-checked the directory. The new flow only resolves; if the directory has been deleted between config load and ingest start, the wave will fan out N tasks that each fail individually with an opaque `FileNotFoundError`. Surface the failure once, at the orchestrator level.

```python
# src/atlas/ingest/wave_runner.py
def start_wave(cfg: AtlasConfig, batch: list[Item]) -> WaveResult:
    root = resolve_wiki_root(cfg)
    if not root.exists():
        raise WaveAbort(f"wiki_root does not exist: {root}")
    ...
```
