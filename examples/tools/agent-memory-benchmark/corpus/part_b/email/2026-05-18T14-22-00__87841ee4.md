**[P2] `ContextSelector` is O(N*M) per wave**

For each item, `select()` iterates every wiki section and runs a string-contains check. Waves of 80 items against a wiki of ~400 sections cost 32k string scans. Build a token-to-section index once per wave and look up each item's tokens against it.

```python
# src/atlas/ingest/context_selector.py
class ContextSelector:
    def __init__(self, sections: list[Section]):
        self._index: dict[str, set[str]] = defaultdict(set)
        for s in sections:
            for tok in s.tokens():
                self._index[tok].add(s.id)

    def select(self, item: Item) -> list[Section]:
        ids: set[str] = set()
        for tok in item.tokens():
            ids |= self._index.get(tok, set())
        return [s for s in self._sections if s.id in ids]
```
