### ReviewBot Summary

This MR introduces a `ContextSelector` that trims the per-item context block in the wave batch prompt. The reported cache hit improvement (71% -> 94%) is plausible — the selector's subset key is deterministic on item content. The implementation has three concerns: the selector uses Python's built-in `hash()` for the subset key (process-local salt; results differ across daemon restarts), the prompt prefix in `wave_batch.md` got reordered in a way that may break the existing prefix cache on the first wave after deploy, and there is no path-shortening for items that match zero wiki sections (an empty context block still adds 40-some tokens of scaffolding).

**Confidence Score: 3/5**

---

**[P1] Subset key uses `hash()` — non-stable across processes**

`context_selector.py` builds the subset key with `hash(tuple(section_ids))`. Python's built-in `hash` is salted by `PYTHONHASHSEED` and differs across process restarts. The whole point of the subset key is to be a cache lookup; if the same input maps to different keys after a daemon restart, the provider-side prefix cache misses for a full wave on every redeploy.

```python
# src/atlas/ingest/context_selector.py
import hashlib

def _subset_key(section_ids: list[str]) -> str:
    canonical = ",".join(sorted(section_ids))
    return hashlib.blake2b(canonical.encode(), digest_size=8).hexdigest()
```

<details>
<summary>Prompt To Fix With AI</summary>

Replace `hash(tuple(section_ids))` in `src/atlas/ingest/context_selector.py` with a `hashlib.blake2b` digest over a canonical (sorted, comma-joined) representation of the section ids. Use an 8-byte digest, render as hex. Add a unit test that constructs the selector twice in separate `subprocess` invocations and asserts the same input yields the same key.

</details>

**[P2] Empty context block emits dead scaffolding**

When `ContextSelector.select(item)` returns `[]`, `prompt_builder` still renders `## Wiki context\n(none)\n\n`. That is ~40 tokens of cache-stable scaffolding per item that the model has no reason to read. Skip the block entirely when empty.

```python
def render_context(sections: list[Section]) -> str:
    if not sections:
        return ""
    body = "\n\n".join(s.render() for s in sections)
    return f"## Wiki context\n\n{body}\n\n"
```
