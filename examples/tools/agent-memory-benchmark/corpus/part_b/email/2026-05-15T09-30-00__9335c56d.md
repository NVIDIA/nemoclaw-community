**[P1] Cache not invalidated on `AtlasConfig.reload()`**

`reload()` rebuilds `self._data` but does not clear `_wiki_root_cached`. Operators who rotate the wiki root via config hot-reload will see new writes still landing in the old directory until the daemon is restarted. This is exactly the silent-misconfiguration shape pass 1's P1 was meant to prevent.

```python
# src/atlas/config/__init__.py
def reload(self) -> None:
    new_data = _load_config_file(self._source_path)
    self._data = new_data
    self._wiki_root_cached = None  # invalidate derived paths
```
