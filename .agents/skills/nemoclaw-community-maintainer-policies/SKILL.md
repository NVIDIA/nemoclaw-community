# NemoClaw Community Maintainer Policies

This package is the canonical maintainer-policy source for NemoClaw Community.

## References

- Read [workflow-policy.md](references/workflow-policy.md) for the source-of-truth hierarchy and authorization boundary.
- Read [triage-instructions.md](references/triage-instructions.md) before classifying an issue or pull request.
- Read [label-taxonomy.md](references/label-taxonomy.md) for human-facing label policy.
- Use [label-taxonomy.json](references/label-taxonomy.json) to validate machine values.
- Read [examples.md](references/examples.md) for representative classifications.

Use plain language and distinguish native Issue Type from PR type, routing,
workflow, example-kind, and provenance labels. Do not invent labels or perform
metadata writes without explicit authorization.
