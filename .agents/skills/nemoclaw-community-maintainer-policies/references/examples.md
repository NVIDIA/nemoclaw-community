# NemoClaw Community Maintainer Examples

## Integration Bug

- Title: `fix(outlook): avoid repeated device login after access-token expiry`
- Native Issue Type: `Bug`
- Labels: `area: integrations`
- Implementing PR: `bug-fix`, `area: integrations`

## New NVIDIA Recipe

- Title: `feat(recipes): add a developer community chief of staff`
- Native Issue Type: `Enhancement`
- Labels: `example: recipe`, `provenance: nvidia`
- Implementing PR: `feature`, `example: recipe`, `provenance: nvidia`

## Partner Recipe Documentation

- Title: `docs(hpe): clarify retail assistant deployment`
- Native Issue Type: `Documentation`
- Labels: `area: docs`, `example: recipe`, `provenance: partner`
- Implementing PR: `chore`, `area: docs`

## Security-Control Change

- Title: `feat(gitlab): add policy-scoped multi-project read access`
- Native Issue Type: `Enhancement`
- Labels: `area: security`
- Implementing PR: `feature`, `area: security`

Do not add legacy issue-type labels or a supplemental public `security` label.
